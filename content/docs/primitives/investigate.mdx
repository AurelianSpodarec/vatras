Find out what is true about an open question.

## What it does

Investigate takes an unanswered question and looks for evidence that can
resolve it.

It uses the available project context, documentation, code, or other
relevant sources rather than guessing.

Investigation should return what was found and any constraints or
uncertainty that remain.

## Example

Question:

```text
Is the eastern entrance to the old mine still accessible?
```

Investigation might find:

```text
The entrance was collapsed during the last siege.
The western entrance remains accessible.
```

## Input

An open question or uncertainty.

## Output

Findings, evidence, constraints, and remaining uncertainty.
