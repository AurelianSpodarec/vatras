Revise an understanding using what has been learned.

## What it does

Iterate takes an existing idea, proposal, or understanding and improves it
using new information.

It does not simply add more detail. The result should reflect what has
changed in the understanding.

## Example

Before:

```text
We should use the old mine to get behind the orcs.
```

After learning that the eastern entrance is blocked:

```text
Use the old mine as a diversion while approaching from the eastern
pass.
```

## Input

An existing idea, proposal, or understanding together with new findings,
constraints, or objections.

## Output

A revised, sharper understanding.
