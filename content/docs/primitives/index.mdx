Primitives are the basic operations Vatras can perform.

A primitive does one kind of work. Flows combine primitives to accomplish
larger kinds of work.

For example:

```text
critique → investigate → iterate
```

Each operation is a primitive. The sequence is a flow.

## Primitives

| Primitive        | What it does                                                              |
| ----------------- | -------------------------------------------------------------------------- |
| **Critique**    | Challenges something and surfaces weaknesses, assumptions and alternatives. |
| **Investigate** | Answers open questions and surfaces findings and constraints.              |
| **Iterate**     | Revises something using what has been learned.                             |
