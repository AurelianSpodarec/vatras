A skill is an artefact that encodes an operation: a file whose content
instructs an agent how to perform a particular piece of work. Defined by
`SKILL.md`, one directory per skill under `skills/`.

See [Skills Map](/docs/skills/map) for how a skill is found and loaded.

| Skill               | Operation | Description                                                   |
| -------------------- | --------- | -------------------------------------------------------------- |
| `vatras:idea` | Capture | Capture an idea in the project's inbox without acting on it. |

This section is generated from `skills/*/SKILL.md` frontmatter — run
`pnpm skills:sync` after adding, renaming or removing a skill. Do not edit it
by hand; edit the skill's frontmatter instead.

The full Idea Inbox API, from [Idea Inbox](/docs/context/ideas):

| Operation | Input | Output | Skill |
| --------- | ----- | ------ | ----- |
| **Capture** | a thought | an entry | `vatras:idea` |
| **Critique** | an entry | objections, hidden assumptions, alternatives | `vatras:critique` |
| **Investigate** | an entry + open questions | findings, constraints | `vatras:investigate` |
| **Iterate** | an entry | a sharper entry | `vatras:iterate` |
| **Duplicates** | the inbox | duplicate ideas | `vatras:duplicates` |
| **Develop** | an entry | critique + investigation + iteration | `vatras:develop` |

Only `vatras:idea` exists as a skill today; the rest are documented but not
yet built.
