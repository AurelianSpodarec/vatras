A skill is an artefact that encodes an operation: a file whose content
instructs an agent how to perform a particular piece of work. Defined by
`SKILL.md`, one directory per skill under `skills/`.

See [Skills Map](/docs/skills/map) for how a skill is found and loaded.

## Available

| Skill               | Operation | Description                                                   |
| ------------------- | --------- | -------------------------------------------------------------- |
| `vatras:init`       | Establish | Initialise a repository for Vatras.                            |
| `vatras:vocabulary` | —         | Establish and maintain the project's ubiquitous language.      |
| `vatras:idea`       | Capture   | Capture an idea in the project's inbox without acting on it.   |

This list matches `skills/` as it stands. A new directory under `skills/`
with a `SKILL.md` adds a skill; nothing here is generated automatically.
