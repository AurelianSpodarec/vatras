A skill is an artefact that encodes an operation: a file whose content
instructs an agent how to perform a particular piece of work. Defined by
`SKILL.md`, one directory per skill under `skills/`.

See [Skills Map](/docs/skills/map) for how a skill is found and loaded.

## Available

{/* skills:start */}

| Skill               | Operation | Description                                                   |
| -------------------- | --------- | -------------------------------------------------------------- |
| `vatras:init` | Establish | Initialise a repository for Vatras. |
| `vatras:vocabulary` | — | Establish and maintain the project's ubiquitous language. |

### Idea Inbox

| Skill               | Operation | Description                                                   |
| -------------------- | --------- | -------------------------------------------------------------- |
| `vatras:idea` | Capture | Capture an idea in the project's inbox without acting on it. |
| `vatras:critique` | Critique | Surface objections, hidden assumptions and alternatives for an idea. |
| `vatras:investigate` | Investigate | Investigate an idea's open questions and return findings and constraints. |
| `vatras:iterate` | Iterate | Sharpen an idea into a clearer entry. |
| `vatras:duplicates` | Duplicates | Find duplicate ideas across the inbox. |
| `vatras:develop` | Develop | Run critique, investigation and iteration on an idea together. |

{/* skills:end */}

This section is generated from `skills/*/SKILL.md` frontmatter, plus
`scripts/idea-inbox-operations.mjs` for Idea Inbox operations that have no
skill yet — run `pnpm skills:sync` after adding, renaming or removing a
skill. Do not edit it by hand.
