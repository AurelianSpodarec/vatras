title: Overview
description: How an AI agent enters, understands, and works within a repository.
---

An AI agent needs more than the codebase to work effectively on a project.

It needs to know where to start, where project knowledge lives, and which
information needs to be available for the work at hand.

Vatras separates this into two parts:

- [**Agent Entry Point**](/docs/context/agent-entry-point) — the starting
  point for an AI agent working in a repository.
- [**Context Architecture**](/docs/context/context-architecture) — the
  structure used to organise persistent project knowledge.

```text
AI Agent
    ↓
Agent Entry Point
    ↓
Context Architecture
    ↓
Project Model
    ↓
Codebase
```

The entry point gets the agent into the project.

The context architecture determines where project knowledge lives and how
it becomes relevant to the work.

## Context is not all loaded at once

A repository can contain more project knowledge than an agent needs for
the current task.

Vatras therefore does not treat all context as equally relevant.

Some context is always in scope. Other context is brought in when the
work makes it relevant.

```text
Context Architecture
    ├── Vocabulary       read on every operation
    └── Other context   read when relevant
```

[**Vocabulary**](/docs/context/vocabulary) is the exception. It lives at
the root of the repository and is read before the work starts, on every
operation, whatever the topic.

An agent cannot reliably interpret project knowledge until it knows what
the project's terms mean.

## Context and work

Primitives and flows operate on the work in front of the agent.

Context provides the durable knowledge that work can rely on and add to.

Not everything produced during an interaction needs to become context.
Only knowledge that remains useful beyond the current interaction needs
to be made durable.

```text
Context
   ↓
Work
   ↓
New understanding
   ↓
Context
```

[**Context Architecture**](/docs/context/context-architecture) describes
how project knowledge is organised and how it becomes available to the
agent.
