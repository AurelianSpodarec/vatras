An AI agent needs more than the codebase to work effectively on a project.

It needs to know where to start, where project knowledge lives, and which information it can rely on.

Vatras separates this into two parts:

- [Agent Entry Point](/docs/context/agent-entry-point) — the starting point for an AI agent working in a repository.
- [Context Architecture](/docs/context/context-architecture) — the structure used to organise persistent project knowledge.

```text
AI Agent
    ↓
Agent Entry Point
    ↓
Context Architecture
    ↓
Project Model
    ↓
Codebase
```

The entry point gets the agent into the project.

The context architecture gives it the knowledge it needs to work within it.

## Vocabulary

Not all of that knowledge is loaded the same way. Most of it is read when it becomes relevant to the work in hand.

[Vocabulary](/docs/context/vocabulary) is the exception. It lives at the root of the repository and is read before the work starts, on every operation, whatever the topic. An agent cannot judge which decisions or research matter to a piece of work until it knows what the words mean.

```text
Context Architecture
    ├── Vocabulary        read on every operation
    └── Everything else   read when it becomes relevant
```

Vocabulary is one part of the context architecture, and the part that is always in scope.
