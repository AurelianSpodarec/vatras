# Context Architecture

Persistent knowledge for working on this repository. Reached from
[AGENTS.md](../AGENTS.md).

This is not the published documentation. The Vatras framework's own
documentation lives in `content/docs/` and is served as the website. This
directory holds the knowledge an agent needs to work *on* the repository.

## Structure

The structure is not a fixed template. It should reflect the knowledge required
to understand, change and maintain this project, and it grows as that knowledge
is established.

```text
docs/
└── README.md    this file
```

Add directories as the knowledge exists to fill them — architecture, decisions,
requirements, domain knowledge, plans. Do not create empty scaffolding ahead of
the content that justifies it.
