# Ideas

An inbox. Nothing here has been decided, and nothing loads this file.

Ideas are captured so they stop occupying attention, not so they influence the
work. Half-formed thoughts in loaded context become assumptions — an agent
reading one cannot tell a stray thought from a settled decision. Keeping this
file unread is what makes it safe to write anything in it.

Newest first. Each entry has an id and the date it was captured.
